# Project: Facial Recognition from Scratch

This repository is based on the work proposed in the following Udemy course:  
https://www.udemy.com/course/python-de-cero-hasta-reconocimiento-facial/

All the content developed here is based on the course instructor’s material, along with the exercises and practical work completed by me (JoseLuisRodriguezLeon) as part of the learning process.

## Description
This repository contains the development of the course **“Python from Zero to Facial Recognition”**, where Python is learned from its fundamentals to the application of **Machine Learning** and **Computer Vision** for facial recognition and object detection.

The project is structured progressively, allowing people with no prior programming experience to advance step by step until implementing basic artificial intelligence systems.

The content follows the course in a guided manner, including **solved exercises, additional practice, and small personal contributions** made during the learning process.

---

## Project Objectives
- Learn Python from scratch.
- Understand the fundamentals of programming.
- Get introduced to computer vision using OpenCV.
- Implement object and geometric shape detection.
- Apply Machine Learning to facial recognition.
- Develop practical projects focused on artificial intelligence.

## Course Content

**Topics:**
- What is Python?
- Visual Studio Code installation
- Creating `.py` files
- Hello World
- Data types
- Comments
- Variables
- Conditionals
- Loops
- Vowels and character handling

### Introduction to Artificial Intelligence
Foundational concepts to start working with computer vision and Machine Learning.

**Topics:**

- OpenCV installation
- Coordinate handling

- Geometric shape detection

### Applied Machine Learning
