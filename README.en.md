## About the Project

This project aims to learn Python from its fundamentals to its application in **computer vision** and **machine learning**, with a focus on facial recognition and object detection.

The repository follows a progressive structure that allows moving from basic programming concepts to the implementation of functional artificial intelligence systems. The code presented here is part of an educational and guided practice process.

[Back to top](#facial-recognition-from-scratch)

---

## Objectives

- Learn Python from scratch.
- Strengthen programming fundamentals.
- Get introduced to computer vision using OpenCV.
- Implement object and geometric shape detection.
- Apply basic machine learning techniques to facial recognition.
- Develop practical projects focused on artificial intelligence.

## Content

### Python Fundamentals
- Introduction to the Python language
- Development environment setup
- Creation and execution of `.py` files
- Data types and variables
- Conditionals and loops
- Basic character handling
- Practical exercises

### Introduction to Computer Vision
- OpenCV installation and usage
- Coordinate handling
- Geometric shape creation
- Geometric shape detection
- Basic object detection
- Initial simple model training

### Applied Machine Learning
- Step-by-step facial recognition implementation
- Vehicle license plate recognition

## Repository Structure

The repository is organized as follows:

- **/Python**  
  Scripts and exercises related to Python fundamentals.

- **/OpenCV**  
  Exercises and practices focused on computer vision and image processing.

- **/MachineLearning**  
  Practical implementations of models applied to facial recognition and detection.

- **/Docs**  
  Additional documentation, notes, and supporting material generated during the learning process.

*(The structure may evolve as the project progresses.)*

## Usage

To run the project scripts:

1. Clone the repository.
2. Ensure Python is installed.
3. Install the required dependencies (for example, OpenCV).
4. Run the `.py` files from the development environment or terminal.

This repository is intended to be explored progressively, following the logical learning sequence.
