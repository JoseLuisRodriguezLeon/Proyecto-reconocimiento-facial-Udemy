**Reconocimiento Facial desde Cero

Este repositorio contiene el desarrollo del curso Python de Cero hasta Reconocimiento Facial, basado en el contenido del siguiente curso de Udemy:
https://www.udemy.com/course/python-de-cero-hasta-reconocimiento-facial/

El trabajo aquí presentado se apoya en el material del instructor y en los ejercicios propuestos en el curso, junto con implementaciones y prácticas realizadas por mí (JoseLuisRodriguezLeon) como parte del proceso de aprendizaje.

Descripción

El proyecto abarca el aprendizaje de Python desde sus fundamentos hasta su aplicación en visión por computador y machine learning, con énfasis en reconocimiento facial y detección de objetos.

La estructura del repositorio sigue un enfoque progresivo, permitiendo avanzar desde conceptos básicos de programación hasta la implementación de sistemas funcionales de inteligencia artificial. El contenido incluye ejercicios resueltos, prácticas guiadas y pequeñas adaptaciones personales realizadas durante el desarrollo del curso.

Objetivos

Aprender Python desde cero.

Consolidar los fundamentos de la programación.

Introducirse a la visión por computador con OpenCV.

Implementar detección de objetos y figuras geométricas.

Aplicar técnicas básicas de machine learning al reconocimiento facial.

Desarrollar proyectos prácticos orientados a inteligencia artificial.
