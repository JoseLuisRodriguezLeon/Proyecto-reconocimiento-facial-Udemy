## Acerca del Proyecto

Este proyecto tiene como objetivo aprender Python desde sus fundamentos hasta su aplicación en **visión por computador** y **machine learning**, con énfasis en reconocimiento facial y detección de objetos.

El repositorio sigue una estructura progresiva que permite avanzar desde conceptos básicos de programación hasta la implementación de sistemas funcionales de inteligencia artificial. El código aquí presentado forma parte de un proceso educativo y de práctica guiada.

[Volver al inicio](#reconocimiento-facial-desde-cero)

---

## Objetivos

- Aprender Python desde cero.
- Reforzar los fundamentos de la programación.
- Introducirse a la visión por computador utilizando OpenCV.
- Implementar detección de objetos y figuras geométricas.
- Aplicar técnicas básicas de machine learning al reconocimiento facial.
- Desarrollar proyectos prácticos orientados a inteligencia artificial.

[Volver al inicio](#reconocimiento-facial-desde-cero)

## Estructura del Repositorio

El repositorio se organiza de la siguiente manera:

- **/Python**  
  Scripts y ejercicios relacionados con los fundamentos del lenguaje Python.

- **/OpenCV**  
  Ejercicios y prácticas orientadas a visión por computador y procesamiento de imágenes.

- **/MachineLearning**  
  Implementaciones prácticas de modelos aplicados al reconocimiento facial y detección.

- **/Docs**  
  Documentación adicional, notas y material de apoyo generado durante el proceso de aprendizaje.

*(La estructura puede evolucionar a medida que avanza el proyecto.)*

## Uso

Para ejecutar los scripts del proyecto:

1. Clonar el repositorio.
2. Asegurarse de tener Python instalado.
3. Instalar las dependencias necesarias (por ejemplo, OpenCV).
4. Ejecutar los archivos `.py` desde el entorno de desarrollo o la terminal.

Este repositorio está pensado para ser explorado de manera progresiva, siguiendo el orden lógico del aprendizaje.
